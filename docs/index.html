爬爬蚁 · 隐私政策

生效日期：2026-09-07 · 最近更新：2026-10-30（调整支持平台与站点权限）· 适用于 Chrome 扩展「爬爬蚁」

1. 引言

本扩展（「爬爬蚁」）帮助用户把自己账号在 抖音创作者中心、微信视频号助手 与 哔哩哔哩创作中心 的数据中心统计导出为 CSV（含作品封面），按上一个月 / 上一周选择周期。B 站作品明细为所选周期发布作品的累计数据。本政策说明本扩展如何处理信息。

2. 我们收集什么

我们不收集任何个人信息。本扩展不收集、不上传、不传输、不出售任何数据。

  • 不采集：不采集账号密码、浏览记录、设备信息、IP 地址或任何可识别身份的数据。
  • 不上传：无远程服务器、无统计 / 埋点 / 遥测、无第三方 SDK。
  • 本地处理：所有数据均只读地在您的浏览器本地处理，产物只导出到您自己的电脑。

3. 数据用途

仅当您主动点击「提取数据」时，扩展才读取您本人已登录账号在官方平台页面上展示的统计数字，并将其整理为 CSV / 封面 ZIP 供您下载。除此之外不做任何其它用途。

4. 数据存储

扩展仅在本地（浏览器 storage）保存最近一次导出结果与状态，用于在您关闭 / 重开弹窗后恢复下载按钮。这些数据不离开您的浏览器，仅本扩展可读，随扩展卸载一起清除。

5. 权限说明

本扩展声明的权限及用途：

  • 下载（downloads）：把导出的 CSV 与封面 ZIP 保存到您电脑（仅点击下载按钮时）。
  • 存储（storage）：在本机保存导出结果与状态（见第 4 节）。
  • 存储空间（unlimitedStorage）：单篇明细较多时结果可能超出浏览器默认的本地存储配额，用它避免写入失败、丢失结果；同样只在本机。
  • 通知（notifications）：提取完成或失败时弹一条本地通知。
  • 站点访问（host permissions）：creator.douyin.com、channels.weixin.qq.com、member.bilibili.com、*.douyinpic.com、finder.video.qq.com、i0.hdslb.com、i1.hdslb.com、i2.hdslb.com —— 仅为读取您已打开页面的数据与下载封面。

注：本扩展不声明任何未使用的权限（如 scripting）。

6. 数据共享

本扩展不与任何第三方共享数据，不连接任何第三方服务器，不使用任何分析或广告服务。

7. 安全

由于所有数据均在您本机处理、且从不离开浏览器，不存在数据传输泄露风险。请仅在您本人或您有权管理的账号上使用本扩展。

8. 您的权利

所有数据仅在您点击「提取数据」时读取，产物保存在您的电脑上，您可以随时删除。卸载扩展即清除其本地存储，不留任何数据。

9. 政策变更

若本政策有重大变更，我们会更新本页并更新生效日期。继续使用即视为同意更新后的条款。
