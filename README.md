# 爬爬蚁（AntClaw）

把自己账号的**创作者数据中心**数据一键导出为 **CSV**（含作品封面 ZIP）的 Chrome 扩展（Manifest V3），支持 **上一个月（自然月）** 与 **上一周（自然周）** 两种周期。

面向 **抖音创作者中心**（`creator.douyin.com`）、**微信视频号助手**（`channels.weixin.qq.com`）、**哔哩哔哩创作中心**（`member.bilibili.com`）。

> **定位与免责**：只读工具。仅在你已登录的官方平台页面上、由你主动点击时，调用平台自身的数据接口读取统计；不绕过任何权限控制、不外发任何数据。请仅用于**本人账号**或**你被授权管理**的账号，并遵守对应平台的服务条款。

---

## 功能特性

- **三个平台**：抖音、微信视频号、哔哩哔哩（同一弹窗内切换）。
- **两种周期**：上一个月（自然月）、上一周（自然周）。
- **三类导出**：
  - 汇总 CSV —— 周期内整体指标
  - 单篇 CSV —— 逐作品明细
  - 封面 ZIP —— 作品封面图打包
- **抖音单篇全接口直取**：标题 / 时长 / 播放 / 点赞 / 评论 / 分享 / 收藏 / 弹幕 / 完播率 / 5秒完播率 / 2秒跳出率 / 平均播放时长 / 涨粉 / 脱粉 / 粉丝播放占比 / 最大流量来源 / 搜索关键词，**秒出、无需逐个打开作品详情页**。
- **视频号企微指标**：单篇包含 企微链接点击次数 / 人数、添加通讯录次数 / 人数。
- **B 站**：账号汇总按北京时间自然周/月累加逐日增量；作品明细导出该周期发布作品的累计计数，以及播放进度和互动等统计。缺失数据留空，不将平均播放进度当作完播率。
- **提取过程可离开**：提取期间可以关掉弹窗，完成后会有系统通知；重新打开弹窗会恢复上次结果，可直接下载。
- **温和的请求节奏**：同一平台两次提取至少间隔 60 秒（按平台独立计时）；列表翻页带间隔与上限，命中上限会明确提示而不是静默截断。

## 安装

### 从源码加载（开发者模式）

1. 获取源码：`git clone https://github.com/coency/chrome-extension-antclaw.git`（或下载仓库 ZIP 解压）。
2. 打开 `chrome://extensions`，右上角开启**开发者模式**。
3. 点「**加载已解压的扩展程序**」，选择**本仓库根目录**（即含 `manifest.json` 的那一层）。
4. 在已登录创作者平台的页面点击扩展图标即可使用。

> 仓库 ZIP 里还包含 `docs/`、`research/`、`tests/`、`README.md`，它们不是扩展运行所需文件；扩展本体位于根目录。

### 使用发布包

发布包命名为 `chrome-extension-antclaw-v<版本号>.zip`，解压后目录结构即为扩展本体（`manifest.json` 位于 zip 根目录），既可「加载已解压的扩展程序」，也可直接上传 Chrome 应用商店。

## 使用方法

1. 先在浏览器登录对应平台：抖音 = `creator.douyin.com`，视频号 = `channels.weixin.qq.com`，B 站 = `member.bilibili.com/platform/data-up/video/`，并让该页面成为**当前标签页**。
2. 点击扩展图标，选择**平台**与**周期**。
3. 点「**提取数据**」。取数通过 API 完成，期间可关闭弹窗、切换其他软件，不必保持浏览器在前台；请保留已登录的平台标签页且不要刷新。完成后会收到系统通知。
4. 提取完成后，点「**下载汇总**」「**下载单篇**」「**下载封面**」分别保存；每次下载都会弹出「另存为」对话框。

## 导出字段

### 微信视频号

- **汇总**：周期, 播放量, 推荐播放量, 分享播放量, 主页播放量, 朋友播放量, 订阅号消息播放量, 关注播放量, 其他播放量, 朋友量, 点赞量, 评论量, 分享量, 关注者量, 关注者总数
- **单篇**：发布日期, 封面, 作品时长, 播放量, 完播率, 平均播放时长, 朋友量, 点赞量, 评论量, 分享量, 关注量, 企微点击次数, 企微点击人数, 添加通讯录次数, 添加通讯录人数

### 抖音

- **汇总**：周期, 投稿量, 主页访问, 总播放量, 总点赞量, 总评论量, 总分享量, 5秒完播率, 2秒跳出率, 封面点击率, 平均播放时长, 粉丝净增, 吸粉量, 脱粉量, 回访粉丝量, 总粉丝量
- **单篇**：作品标题, 发布日期, 封面, 作品时长, 播放量, 点赞量, 评论量, 分享量, 收藏量, 弹幕量, 完播率, 5秒完播率, 2秒跳出率, 平均播放时长, 涨粉量, 脱粉量, 粉丝播放占比, 最大流量来源, 搜索关键词

### 哔哩哔哩

当前作品明细仅接入视频稿件，未接入图文、专栏和动态。汇总中的粉丝净增、空间访客属于账号指标，不能解释为仅由视频带来的数据。

- **汇总（12 列）**：周期、开始日期、结束日期、播放量、点赞量、收藏量、投币量、评论量、弹幕量、分享量、粉丝净增、空间访客（逐日人数合计）。指标来自账号逐日趋势，包含历史作品在该周期的贡献。访客是每天人数相加，未跨日去重。
- **单篇基础字段（12 列）**：作品标题、发布日期（北京时间）、封面、作品时长（秒）、播放量、点赞量、涨粉量、评论量、收藏量、投币量、分享量、弹幕量。字段名称省略「累计」，计数仍采用累计口径。
- **单篇新增字段（7 列，共 19 列）**：取关量、平均播放进度、占总时长比、游客播放占比、3秒跳出率（发稿后14天）、互动率（发稿后14天）、播转粉率。
- 以 `pubtime` 选择在该周期发布的作品，**作品计数为累计值，不是周期内增量**。播放、点赞和涨粉来自列表 `stat.play / stat.likes / stat.fans`，五项补充互动来自单篇概览 `stat.comment / stat.fav / stat.coin / stat.share / stat.dm`；进度及其占比来自播放分析 `quit_info`，其他扩展统计来自稿件对比 `stat`。不混用 `real_stat` 或 `hour_stat`，不将缺失值补成零。不同接口更新时间可能有差异。
- **平均播放进度与占总时长比分列**：播放分析 `quit_info.avg_play_progress` 为每次播放最大观看进度的平均秒数，按官网向下取整显示为“0分20秒”等；`quit_info.full_play_ratio` 原值除以 100，保留一位小数显示为“67.5%”等。两列分别读取，不通过已取整的秒数反算百分比。`avg_play_time` 是实际观看耗时，含义不同，仍不导出。没有确认可靠的独立完播率字段，因此不导出完播率。
- 进度接口按 CID（分 P）查询：优先使用列表的 `videos`，缺失时通过 `v3/archive/view` 查询。仅对明确为单 P 的作品获取进度；多 P 作品这两列留空并提示，不将第一 P 的数据当整篇作品统计。缺少或异常字段各自留空，不补零，不回退为对比接口的另一种进度展示。
- 其他比率保留两位百分数小数，直接采用对比接口对应字段。3 秒跳出率读取 `stat.crash_rate`，表示该作品整体播放不足 3 秒的播放量占总播放量的比例，涵盖粉丝及游客，不是账号整体指标。互动率可以超过 100%。
- 平台部分指标只统计发稿后 14 天，已在相关列名标注，不能理解为所选自然周/月内的比率。取关量仅适用于 2024-06-01 起发布的作品。
- 部分账号或作品可能不返回进度、比率等字段；对应列留空并提示，不做推算。尚未确认周期末总粉丝、独立完播率及其他字段的可靠来源或单位，不导出这些字段。
- 汇总从近 90 天逐日数据筛选自然周/月，每个指标都校验完整日期覆盖；缺日、重复日期或无效数值时，该列留空并提示。全部汇总指标不可用时禁用「下载汇总」，有效作品明细仍可导出。
- 封面支持 `i0/i1/i2.hdslb.com`，文件名形如 `01_BVxxxxxxxxxx.png`，扩展名沿用链接中的图片格式。

### 导出文件命名

| 内容 | 命名示例 |
|---|---|
| 汇总 CSV | `抖音_2026年08月_月度汇总数据统计.csv` |
| 单篇 CSV | `抖音_2026年08月_月度作品数据统计.csv` |
| 封面 ZIP | `抖音_2026年08月_月度作品封面.zip`，内部为 `01_<作品ID>.jpg`（视频号用发布时间戳） |

- CSV 为 **UTF-8（带 BOM）**，Excel 双击打开不乱码。
- 以 `=` `+` `-` `@` 开头、且**不是纯数字**的文本（标题、关键词等）会被加上前置 `'`，避免被 Excel/Sheets 当成公式执行；负数（如粉丝净增 `-3`）与百分比、科学计数不受影响。

## 已知限制

- 抖音单篇来自列表接口 `work_list` 直取（秒出、不打开任何页面）。完播率 / 5秒完播率 / 2秒跳出率 / 平均播放时长 / 涨粉量 / 脱粉量 在抖音**汇总**中为整周期汇总（非单条）。
- 【最大流量来源 / 搜索关键词】为每篇额外调用 `item/play/source`、`item_analysis/search/keyword` 获取；涨粉量对无涨粉作品为空。
- 视频号单篇的 完播率 / 平均播放时长 来自 `post_list`，已包含在单篇 CSV 中。
- 为控制请求量，抖音作品列表最多翻 200 页（约 8000 条）、视频号单篇最多 50 页（约 5000 条）；一旦命中上限，会在结果提示里说明「仅导出前 N 条」，不会静默截断。抖音列表按时间倒序翻页，翻到所选周期起点之前即停止。
- 视频号的渠道来源分解依赖接口返回的渠道名；平台新增或改名时，未识别渠道会并入「其他」（总量不受影响）。
- 视频号接口依赖 Web 端固定参数（`_aid` 等）与页面内的账号标识；平台改版可能导致失败，需随版本更新维护。
- B 站列表每页 20 条，最多 200 页，页间隔 600ms。按 BV 号（缺失时用 AV 号）去重；不假定接口返回顺序可用于提前停止。分页异常、上限和中途失败均提示可能不完整，并保留已取得的作品。
- B 站补充互动仅对所选周期内去重后的作品查询，每篇一次，最多两并发，每个工作流的相邻请求间隔 600ms。缺少 BV 号、接口失败或字段缺失时，新列留空并提示；登录失效后停止新补充请求，保留已有数据。作品较多时提取耗时会增加。
- B 站扩展统计每批最多 10 篇、最多两批并发，按 BV 号精确关联响应。遗漏或重复匹配的作品留空，忽略响应中的其他推荐作品；不按响应顺序拼接。新增汇总分别请求，避免一个不支持的指标影响其余结果。
- B 站首次发稿前或最新一天的数据可能尚未生成，日期不完整的汇总不填零。不能把已筛选作品的累计播放之和当作账号月度播放量。

## 常见问题

- **点「提取数据」提示先打开并登录平台？** 当前标签页不是所选平台。先打开并登录对应页面（抖音 `creator.douyin.com` / 视频号 `channels.weixin.qq.com` / B 站 `member.bilibili.com`），再回弹窗点击。B 站主站 `www.bilibili.com` 不是创作中心。
- **提示「登录已失效」？** 刷新对应平台页面后重试。
- **下载按钮是灰的？** 按钮只对有效结果开放；无作品时不能下载明细，无可用封面时不能打包，B 站汇总全部缺失时不能下载汇总。具体原因见结果提示。
- **提取中关掉弹窗会丢数据吗？** 不会。结果已写入本地存储，完成后有系统通知；重新打开弹窗会恢复并可直接下载。
- **为什么不能连续点「提取数据」？** 同一平台有 60 秒冷却（按平台独立计时），用于降低对平台接口的压力；提取失败后是 5 秒短冷却。
- **封面 ZIP 里少了几张？** 封面链接有有效期，过期或域名不可达会失败；状态栏会显示失败张数与域名。
- **抖音某些列为空？** 涨粉量对无涨粉作品为空；「最大流量来源 / 搜索关键词」接口失败时会提示失败篇数。
- **换台电脑还能看到上次结果吗？** 不能，结果只保存在本机浏览器里。
- **扩展更新后原来的页面报错？** 内容脚本需要重新注入，扩展会尝试自动刷新该页一次；也可手动刷新。

## 错误提示

- **登录已失效**（请先登录对应平台）：
  - 视频号（`errCode` = 300333 / 300334）：`登录已失效（汇总接口错误码300333：{errMsg}），请先登录「视频号」后再操作（若已登录请刷新页面重试）`；单篇接口失败会标明「单篇接口错误码」。
  - 抖音（`status_code` = 8）：`登录已失效，请先登录「抖音」后再操作（若已登录请刷新页面重试）`
- **请求被平台拒绝**（视频号 `errCode` = 300800，`errMsg` 常见为 `request failed`）：`视频号汇总请求被平台拒绝（错误码300800：request failed）：请刷新页面后重试…`。**这不是登录问题**，通常是请求参数不被平台接受。排查线索：控制台 `[AntClaw]` 那行会打印失败的接口、错误码与本次请求区间。
  - 已知案例：统计区间必须对齐到自然日（`endTs` 取最后一天 `00:00:00`）。把 `endTs` 改成 `23:59:59` 会让区间变成「30 天 23:59:59」，平台直接返回 300800。
- **未找到视频号账号标识（finder id）**：`未找到视频号账号标识（finder id）：请确认当前浏览器已登录视频号助手，然后刷新该页面重试（F12 控制台会打印相关键名）`。这是**本地读取页面登录标识失败**，与接口登录态无关，先刷新页面；仍失败时把控制台 `[AntClaw]` 打印的键名发出来。
- **其它接口错误**（错误码 + 原始信息）：
  - 视频号：`视频号数据获取失败！错误码{code}：{msg}`
  - 视频号单篇：`视频号单篇数据获取失败！错误码{code}：{msg}`
  - 抖音：`抖音数据获取失败！错误码{code}：{msg}`
- **HTTP 错误**（不重试，直接提示）：`请求失败（HTTP {status}）：请确认已登录对应平台后再操作`
- **请求失败**（网络错误 / 超时 / 返回内容无法解析，重试 3 次后）：`请求失败：请确认已登录对应平台后再操作（若已登录请刷新页面重试）`。单次请求 20 秒超时，覆盖接收响应头和读取 JSON 正文全过程。
- **部分成功会以 ⚠ 提示**（结果区第二行起），不会只给一半数据却不说话：
  - 汇总成功但单篇失败 → 提示可重试；
  - 视频号汇总、来源或关注者字段缺失/异常 → 对应单元格留空并提示，保留真实零值；不使用可能重叠的渠道分解代替总量；
  - 粉丝 / 关注者数据为空 → 提示对应列为空；
  - 作品列表分页游标未推进 → 提示可能只抓取了部分作品；
  - 「最大流量来源 / 搜索关键词」有 N 篇失败、或部分明细接口提示登录失效；
  - 结果写入本地存储失败（如超配额）→ 提示尽快下载，因为关闭弹窗后可能无法恢复。

## 开发

无构建步骤、无第三方依赖，直接改源码即可；改完后到 `chrome://extensions` 点「**重新加载**」，再刷新平台页面。

### 代码结构

| 文件 | 职责 |
|---|---|
| `manifest.json` | MV3 清单：权限、host 权限、内容脚本注入范围、弹窗与后台声明 |
| `content.js` | 三个平台共用的消息路由、请求与 CSV 工具，及抖音/视频号提取逻辑 |

| `popup.html` / `popup.js` | 弹窗界面：平台/周期选择、提取触发、下载（CSV / 手写 ZIP）、冷却与状态提示 |
| `background.js` | Service Worker：跨标签页任务互斥、冷却、结果/错误持久化及完成/失败通知 |

| `data/item_analysis/search/keyword` | 单篇「搜索关键词」|

|---|---|
| `POST /cgi-bin/mmfinderassistant-bin/statistic/new_post_total_data` | 周期汇总与渠道来源分解 |
| `POST /cgi-bin/mmfinderassistant-bin/statistic/fans_trend` | 关注者量 / 关注者总数 |
| `POST /micro/statistic/cgi-bin/mmfinderassistant-bin/statistic/post_list` | 单篇明细（含企微 4 个字段，必须走 `/micro/` 路径）|

B 站（前缀 `https://member.bilibili.com/x/web/data/`）：

| 接口 | 用途 |
|---|---|
| `GET v2/overview/stat/graph?period=2&s_locale=zh_CN&type=play,like,fav,coin,comment,dm,share,fan` | 近 90 天多指标逐日数据，按所选自然周/月校验并汇总 |
| `GET archive/index?pn=<页码>&ps=20&scene=archive_compare&order=0` | 作品列表，读取发布时间、元数据和 `stat` 累计统计 |
| `GET archive_diagnose/overview?bvid=<作品BV号>` | 单篇累计评论、收藏、投币、分享、弹幕 |

### 维护提示

- 抖音的统计区间以请求体里的 `date_range` 为准；`recent_days` 仅为与前端请求形态保持一致，**不要**用它推导周期。
- 视频号的 `_aid`、`_rid`、`_pageUrl` 是 Web 端固定参数与随机串，平台改版时需同步更新。
- 视频号的统计区间**必须对齐到自然日**（`startTs` / `endTs` 都取 `00:00:00`），平台**按自然日含当天**统计：2026-09-30 真机对比确认，本扩展「上一个月」汇总`播放量`与视频号助手后台数字一致，末日数据没有丢失，`endTs` 保持 `00:00:00` 即可。
  - 反面案例：曾把 `endTs` 改成 `23:59:59`，区间变成「30 天 23:59:59」，平台直接返回 `300800 request failed`（这个错误码曾被误判为登录失效，现已拆分文案）。
  - 若将来再怀疑末日缺失，仍以「与后台数字对比」为准，**不要凭猜改区间**。
- 所有接口返回的数字 / 数组字段都做了类型保护：结构变化时会在结果里以 ⚠ 提示，而不是抛出 `a.reduce is not a function` 这类错误。
- 使用 `node --test tests/*.test.cjs` 运行回归测试（无需安装依赖）。测试通过后，仍需在真实登录页面验证三个平台的提取与导出。

### 打包发布

发布包只包含扩展本体，排除 `.git`、`docs/`、`research/`、`tests/`、`README.md`、`LICENSE`，且**文件位于 zip 根目录**（`manifest.json` 在根，可直接上传商店）：

```powershell
$v = (Get-Content manifest.json -Raw | ConvertFrom-Json).version
Compress-Archive -Path manifest.json,background.js,content.js,bilibili.js,popup.html,popup.js,icon16.png,icon32.png,icon48.png,icon128.png `
  -DestinationPath "chrome-extension-antclaw-v$v.zip" -Force
```

- 命名规则：`chrome-extension-antclaw-v<版本号>.zip`。
- 作为 Chrome 应用商店 的**更新**上传时，`manifest.json` 的 `version` 必须高于已发布版本。

  - 按用户要求取消小红书功能，移除平台选项、提取代码、站点权限及临时验证入口；升级后忽略其旧任务和结果，避免影响其他平台；
  - 移除 B 站固定日期的临时样本功能；
  - 新增 B 站自然周/月汇总、周期内发布作品累计明细和封面 ZIP；
  - B 站作品明细补充累计评论、收藏、投币、分享、弹幕；支持缺失留空、部分失败保留和登录失效停止补充请求；

  - 视频号周/月区间的结束时间保持最后一天 `00:00:00`，与平台按自然日含当天统计的口径一致；
  - 抖音补充明细接口检查业务错误码，登录失效或接口失败不再伪装成「暂无数据」；
  - 提取期间禁用平台/周期切换，后台统一拦截跨标签页重复任务并执行冷却；
  - 失败原因保存在本机，完成与失败均广播状态并发送系统通知，重新打开弹窗可恢复；
  - 渠道来源分解改为累加，同名渠道不再互相覆盖；
  - 接口字段类型保护，缺失或异常时给出 ⚠ 提示（原先可能静默为空或抛出不可读错误）；
  - 抖音作品列表按统计区间提前结束翻页，命中页数上限 / 游标异常时明确提示；
  - 下载的 objectURL 改为等下载结束再释放，封面改为并发取图并显示进度与失败域名；
  - CSV 公式注入防护补全；新增 `unlimitedStorage`，避免大结果写入本地失败。
